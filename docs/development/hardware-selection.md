# Hardware Selection & Procurement Rules

Physical AI Robotにおけるハードウェア採用・購入前の必須確認ルール。
設計・開発の一般フローは `docs/development/workflow.md` に従う。

## 1. 基本原則

- **必須条件を先に確認する**：物理的な接続・寸法・干渉、電気的互換性・電源容量、OS・ドライバ・ソフトウェア対応を確認する。
- **致命的なリスクを未解決のまま先へ進めない**：購入後の調整で対応できる事項と、購入前に成立性を確認すべき事項を区別する。後者が未解決なら採用・購入を保留する。
- **証拠と不確実性を区別する**：実機確認済み、公式仕様で確認済み、推定、未確認を明示する。個別部品の公式対応から複合構成の動作保証を推論しない。
- **調達可能性も必須条件とする**：本体だけでなく、ネジ、スペーサー、ケーブル、電池、コネクタ、工具等、成立に必要な全構成部品を対象とする。
- **既存の動作確認済み構成を優先する**：変更が必要なら理由、影響、検証手順を記録する。
- **製品単体ではなく構成全体で判断する**：必要部品の入手、総費用、組み立て、安全性、運用を確認する。

## 2. 購入前ゲート（必須）

採用・購入推奨の前に、次の各項目に証拠と判定を記録する。

| 項目 | 確認事項 |
| --- | --- |
| 機械・組み立て | 固定穴、基板間距離、干渉、向き、ケーブル長、ネジの規格・有効ねじ込み長、組立順、メンテナンス性 |
| 電気・安全 | 入出力電圧、電流・電力余裕、給電経路、GPIO/I2C/SPI等の競合、逆給電、電池の仕様と安全上の制約 |
| ソフトウェア | 実機OS・カーネル・ドライバ・ファームウェアとの互換性、必要な設定、既存構成への影響 |
| 調達 | **日本国内から実際に注文可能か**、販売元、在庫、型番・リビジョン、数量、納期、返品条件、代替品 |
| 費用 | 本体・必須追加部品・送料・税金・海外輸入時の追加費用を含む**購入総額** |
| 検証 | 組み立て前の確認、電源投入前の確認、実機テスト手順、失敗時の切り戻し |

- 在庫・価格・送料・納期は変動するため、**確認日・販売元・商品URL**を残し、購入直前に再確認する。
- 国内在庫がない場合は、海外送料、輸入関連費用、納期、返品難易度を明記する。総額不明なら「費用未確認」とする。
- 必須部品が入手できない場合は「本体だけ購入」を推奨しない。
- 推測で「取り付くはず」「問題なさそう」をゲート通過として扱わない。公式図面・マニュアル・実機寸法・メーカー回答等を優先する。
- 実物が届かないと確認できない項目は、その理由と、失敗した場合の対処策・返品可否・許容損失を示す。成立を左右する重要リスクで代替策がなければ購入保留とする。

## 3. 判定ルール

| 判定 | 条件 | 対応 |
| --- | --- | --- |
| 採用可能 | 必須の技術・安全・調達条件を満たし、総額と検証方法が明確 | 購入候補として確定。購入直前に在庫・価格を再確認 |
| 保留 | 重要な未確認事項、調達不明、総額不明、解決策未確定がある | 調査・図面照合・メーカー問い合わせを優先。後続の詳細選定を確定させない |
| 不採用 | 重大な不適合、調達不能、許容できない費用・リスク | 代替構成を評価 |

保留は失敗ではない。先に確認すべきリスクを明らかにした状態であり、未解決のまま採用可能と表現しない。

## 4. 選定記録テンプレート

- 目的と必須要件：
- 現行の動作確認済み構成：
- 候補製品・型番・リビジョン：
- 接続図・組立方法（ネジ・スペーサー・配線を含む）：
- 機械・電気・ソフトウェア適合性（確認済み／推定／未確認）：
- 必須追加部品と購入先・在庫：
- 本体・追加部品・送料・税等の総額：
- 情報源・確認日：
- 未解決リスク・失敗時の代替策：
- 購入前ゲート判定（採用可能／保留／不採用）：
- 購入後の実機検証・切り戻し手順：

重要な採用判断は必要に応じて `docs/decisions/` のADRに記録する。実際の動作結果のみを `docs/progress/` に記録する。

## 5. 現在の適用対象：X1201 UPS候補

Raspberry Pi 5 + AI HAT+ 2 + Whisplay HATへのX1201追加は、**現時点で採用保留**。

少なくとも以下を購入前に解決する。

1. X1201とAI HAT+ 2が同じ取り付け穴を使用する場合の、具体的な固定方法と組立順（ポゴピンの指定接触距離を保持）。
2. 積層状態の干渉、ネジ・スペーサー・ケーブル等の必要部品の品番と調達可能性。
3. 3基板全体の給電・GPIO等の互換性と電力余裕。
4. X1201、適合電池、固定部品を含めた実購入可能な構成と税込・送料込み総額。

「X1201単体がPi 5に対応する」ことを「本プロジェクトの積層構成で使用できる」ことの証明としない。
